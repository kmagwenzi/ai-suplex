# AI-Suplex Review Cadence

This file defines when memory is reviewed and improved.

## Per Session

At the end of every session:
- capture execution results,
- write the session end report,
- compress the session into an episode,
- extract candidate lessons,
- save selected bridge-state to cortexmem if needed.

## Weekly Review

Once per week:
- review recent episodes,
- promote repeated lessons,
- refresh procedural files,
- update semantic files if stable changes emerged,
- update the memory index,
- check for contradictions,
- sync important bridge-state into the markdown vault.

## Cycle Review

At the end of each cycle:
- consolidate stable truths,
- retire stale procedures,
- deprecate outdated memory,
- rebuild workflows if needed,
- ensure the vault reflects the current operating model.

## Review Outputs

Each review should produce at least one of the following:
- updated lessons,
- updated semantic files,
- updated procedural files,
- updated index,
- deprecation notes,
- or a short review summary.

## Cadence Rule

Do not wait too long to review memory.

Short feedback loops create better memory than large, delayed cleanups.
