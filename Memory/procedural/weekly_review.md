# AI-Suplex Procedural Memory — Weekly Review

## Purpose
Review the week's sessions, extract patterns, and improve the system.

## Procedure
1. Read recent episodic records.
2. Compare repeated insights and repeated failures.
3. Promote stable lessons into semantic or procedural memory.
4. Update the memory index.
5. Check for contradictions.
6. Refresh trackers, MOCs, and related project files.
7. Record the week's major learnings.

## Rules
- Prioritize repeated evidence.
- Do not over-promote from a single session.
- Resolve conflicts carefully.
- Keep the review concise and actionable.

## Notes
Weekly review is where short-term execution becomes better long-term memory.
