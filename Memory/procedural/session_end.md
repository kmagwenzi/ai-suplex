# AI-Suplex Procedural Memory — Session End

## Purpose
Close an execution session with a complete report and memory capture.

## Procedure
1. Review what was completed.
2. Identify what was incomplete.
3. Capture artifacts produced during the session.
4. Record insights, lessons, and B-Bombs.
5. Note blockers or issues.
6. Write the session end report.
7. Prepare the session for episodic compression.

## Rules
- Be honest about outcomes.
- Separate completed work from unfinished work.
- Capture useful learnings clearly.
- Keep the report structured and reviewable.

## Notes
This workflow closes the execution loop.
