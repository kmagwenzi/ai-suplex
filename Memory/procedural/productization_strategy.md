# AI-Suplex — Productisation & Monetisation Model

**Purpose:** The generic three-layer productisation model behind any framework-turned-product. Capture how an open-core framework becomes a sustainable business — the *model*, not a specific pricing plan.

---

## 🎯 The Core Insight

A framework hides three distinct products. Each serves a different market. Each has a different price. Together they form a pipeline from free to premium.

```
LAYER 1: Open Source Foundation (Community / Lead Gen)
↓
LAYER 2: Product (Self-Service / One-Time Purchase)
↓
LAYER 3: Managed Service (High Touch / Recurring)
```

---

## 💰 Layer 1 — Open Source Foundation

| Asset | What | Model |
|-------|------|-------|
| **Free core** | The open framework — flat structure, core macros, core patterns | Lead gen → upgrades |
| **Fork of a MIT tool** | The fork-own-brand-sell pattern: take a permissive codebase → specialise → brand → sell | Branded product layer |
| **Free patterns** | A reduced set of public patterns | Community building → paid editions |

**The fork pattern** (Cursor from VS Code, Windsurf from VS Code):
- Find a permissive (MIT/Apache) base.
- Fork it → rebrand → pre-configure for your framework.
- Sell the specialised version, standalone or bundled.
- Ride their upstream updates without funding their engineering.

---

## 🛒 Layer 2 — Product (Self-Service)

| Product | What It Is |
|---------|-----------|
| **Full edition** | The complete framework — memory stack + CLI + patterns |
| **Client interface** | A branded fork of a Q&A layer, pre-configured for client workspaces |
| **Pattern pack** | Additional channel- or industry-specific patterns |

**Bundling:** sell the base, upsell the interface and the packs as add-ons.

---

## 🤝 Layer 3 — Managed Service (Recurring Revenue)

| Service | What You Do | What Client Gets |
|---------|-------------|-----------------|
| **Session execution** | You run sessions, write reports, run promotion | Weekly insight without managing the framework |
| **Project memory** | Full vault management + client workspace + interface | "Ask my project manager anything" |
| **White-label agency** | Rebrand the interface for their clients | Agencies resell to their clients |

**Why this works:**
- Clients pay for **answers, not tools**.
- You charge for **structured execution + memory management**.
- The framework scales — adding a client adds one focus area.
- Recurring revenue compounds like memory.

---

## 🏗️ The Fork Pattern (Cursor / Windsurf / Zed model)

Open-source project → fork → specialise → brand → sell.

| Base | Fork | Specialisation |
|------|------|----------------|
| VS Code (MIT) | Cursor | AI agent programming |
| VS Code (MIT) | Windsurf | Cascade AI, deep code understanding |
| VS Code (MIT) | Zed | Collaborative editing, performance |
| Any permissive base | Your fork | Your framework's workspaces, prompts, sync |

**How to execute:**
1. Fork a permissive-licensed base.
2. Rebrand — your name, logo, colours.
3. Pre-configure — add a framework workspace template.
4. Pre-build prompts — "Summarize this week," "What are the blockers," "Show deliverables."
5. Build installers — one-click setup.
6. Sell or bundle.

---

## 📊 Pricing discipline

- One price per product, stated on the storefront; never quote a number that is not there.
- The free tier is lead generation; the product is the conversion; the service is the compounding.
- Revisit pricing on a cadence, from actuals, never from a forecast alone.
