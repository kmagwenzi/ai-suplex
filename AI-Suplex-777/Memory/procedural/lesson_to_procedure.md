# AI-Suplex Procedural Memory — Lesson to Procedure

## Purpose
Turn repeated lessons into reusable procedures.

## Procedure
1. Review lessons for repetition.
2. Identify a workflow pattern that appears more than once.
3. Rewrite the pattern as clear steps.
4. Add the steps to a procedural file.
5. Update related prompt patterns if needed.
6. Refresh the index.

## Rules
- Only promote lessons that are demonstrably reusable.
- Keep procedures short and precise.
- Make the steps easy to apply again.
- Avoid turning a one-off event into a rule.

## Notes
This is how learning becomes automation.
