# AI-Suplex Procedural Memory — Promotion Rules

## Purpose
Define how lesson candidates become durable memory.

## Procedure
1. Compare the candidate against existing memory.
2. Check whether the pattern is repeated and reliable.
3. Decide whether it belongs in semantic memory, procedural memory, lessons, or deprecation.
4. Update the correct file.
5. Refresh the index if needed.

## Rules
- Promote only when evidence is strong.
- Keep repeated workflows in procedural memory.
- Keep stable facts in semantic memory.
- Keep uncertain ideas in lessons.
- Deprecate superseded memory instead of deleting it immediately.

## Notes
This workflow keeps the vault selective and useful.
