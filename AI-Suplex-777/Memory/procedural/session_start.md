# AI-Suplex Procedural Memory — Session Start

## Purpose
Convert an approved Tasklist into an active execution session.

## Procedure
1. Read the active Tasklist.
2. Confirm the tasklist is ready for execution.
3. Load relevant semantic memory and recent episodic context.
4. Create the session start file or prompt.
5. Mark the Tasklist as now in execution.
6. Set success criteria and session intent.

## Rules
- Keep the session focused on the active Tasklist.
- Do not begin unrelated work.
- Preserve the mission structure.
- Make the start state clear and actionable.

## Notes
This workflow bridges planning and live execution.
