# AI-Suplex Procedural Memory — Tasklist Generation

## Purpose
Turn raw to-dos, mission goals, or project requirements into a structured AI-Suplex Tasklist.

## Procedure
1. Read the source input.
2. Identify the mission goal and main focus.
3. Assign roles where relevant.
4. Break the work into sessions if needed.
5. Define success criteria.
6. Add frontmatter and execution structure.
7. Output the finished Tasklist in the expected format.

## Rules
- Follow the current Tasklist pattern.
- Keep the output structured and actionable.
- Do not invent unsupported details.
- Keep the result ready for execution.
- Include memory reflection if the pattern requires it.

## Notes
This workflow is the entry point for turning planning into execution.
