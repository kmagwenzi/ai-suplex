## 🎯 The Core Insight

AI-Suplex has three distinct products hidden inside it. Each serves a different market. Each has a different price. Together they form a pipeline from free to premium.

```
LAYER 1: Open Source Foundation (Community / Lead Gen)
↓
LAYER 2: Product (Self-Service / One-Time Purchase)
↓
LAYER 3: Managed Service (High Touch / Recurring)
```

---

## 💰 Layer 1: Open Source Foundation

| Asset | What | Revenue Model |
|-------|------|--------------|
| **Core Edition** (free) | Flat vault, 5 macros, 2 patterns | Lead gen → upgrades to 7-7-7 |
| **Fork of AnythingLLM** (MIT) | The fork-own-build pattern. Take MIT codebase → specialize → brand → sell. | Branded product layer |
| **Prompt patterns** (free tier) | Reduced set of public patterns | Community building → paid editions |

**The fork pattern** (like Cursor from VS Code, Windsurf from VS Code):
- AnythingLLM is MIT-licensed
- Fork it → rebrand → pre-configure for AI-Suplex vaults
- Sell the specialized version as a standalone product or bundle it with 7-7-7
- Ride their updates without paying for their engineering

## 🤝 Layer 3: Managed Service (Recurring Revenue)

| Service | Price | What You Do | What Client Gets |
|---------|-------|------------|-----------------|
| **Session Execution** | $200/mo per client | You execute sessions, write reports, run promotion | Weekly insights without managing the vault |
| **Project Memory** | $300/mo per client | Full vault management + client workspace + interface | "Ask my project manager anything" via desktop app |
| **White-Label Agency** | $99/mo | Rebrand the interface for their clients | Agency resells to their clients |

**Why this works:**
- Clients pay for **answers, not tools**
- You charge for **structured execution + memory management**
- The vault scales infinitely — adding a client adds one focus area
- Recurring revenue compounds like memory

## 🏗️ The Fork Pattern (Cursor / Windsurf / Zed Model)

Open-source project → fork → specialize → brand → sell.

| Example | Base | Fork | Specialization |
|---------|------|------|--------------|
| Cursor | VS Code (MIT) | Cursor | AI agent programming, inline edits, multi-file edits |
| Windsurf | VS Code (MIT) | Windsurf | Cascade AI, deep code understanding |
| Zed | VS Code (MIT) | Zed | Collaborative editing, performance, AI integration |
| **Antigravity (concept)** | **AnythingLLM (MIT)** | **[Your fork]** | **AI-Suplex vault workspaces, client prompts, sync built in** |

**How to execute:**
1. Fork the AnythingLLM repo (MIT, open source)
2. Rebrand — your name, your logo, your colors
3. Pre-configure — add an "AI-Suplex Workspace" template
4. Pre-build prompts — "Summarize this week," "What are blockers," "Show deliverables"
5. Build installers — one-click setup for clients
6. Sell or bundle — standalone subscription or bundled with 7-7-7

## 📊 Quick Math

### Product-Only (Self-Service)
```
100 sales × $29 = $2,900
50 upsells × $49 = $2,450
= $5,350 one-time revenue
```

### Service-Heavy (Managed Clients)
```
2 clients × $200/mo = $400/mo
3 clients × $300/mo = $900/mo
= $1,300/mo recurring
```

### Mix
```
2 managed clients ($500/mo) + 10 product sales ($290/mo)
+ 5 Antigravity subs ($45/mo) = $835/mo sustainable
→ Scale clients to 10 × $300 = $3,000/mo
```
