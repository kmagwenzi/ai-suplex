# AI-Suplex Procedural Memory — Cycle Review

## Purpose
Review an entire cycle, consolidate durable knowledge, and retire stale material.

## Procedure
1. Read all relevant weekly reviews and episodic files for the cycle.
2. Identify stable truths that should remain in semantic memory.
3. Identify workflows that should remain in procedural memory.
4. Mark outdated memory for deprecation.
5. Update the memory index.
6. Refresh cycle-level trackers and summaries.
7. Document the cycle's major outcomes and changes.

## Rules
- Focus on durable changes, not minor fluctuations.
- Prefer stable evidence over momentary excitement.
- Keep the architecture clean and current.
- Use the cycle review to reset and improve the system.

## Notes
Cycle review is the system's larger calibration loop.
