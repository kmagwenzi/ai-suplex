# 🦸 AI‑Suplex Glossary – 7‑7‑7 Edition

**TWABAM ⚡!** This glossary defines every term you'll encounter in the 7‑7‑7 Edition. Core terms are included, with new concepts marked `[7‑7‑7]`. Use this as your reference.

---

## 🎯 Core Concepts (Same as Core Edition)

### AI‑Suplex
The overall system that combines AI partnership, role‑based execution, energy management, and systematic improvement. It’s a **mindset and a toolset** for solo founders, freelancers, and creators.

### Deep Ultra Mode
A high‑intensity execution state using AI tools to their fullest. Characterised by clear objectives, time‑boxed sessions, and sustained **Twabam ⚡** energy.

### Twabam ⚡
The explosive energy that fuels Deep Ultra Mode. Derived from Zimbabwean slang, it means **“strike with transformative energy!”** Use it as a battle cry after wins.

### 7‑7‑7 Cycle `[7‑7‑7]`
The foundational rhythm of AI‑Suplex:
- **7 weeks** = one working cycle
- **7 cycles** = one working year (≈49 weeks)
- **7th week** = review and strategic reset

In the 7‑7‑7 Edition, your sessions, artifacts, B‑Bombs, and insights are organised by **Cycle X** and **Week Y**.

## 💣 Artifacts & Deliverables

### Artifact
A work‑in‑progress asset – code, diagram, note, prompt, or design. Not yet polished, but captured with context so you can return to it later.

### B‑Bomb 💣
A **production‑ready artifact** that needs no revisions. Portfolio‑grade. Can be sold as a digital product, used in client work, or reused as a template.

> [!hint] **Why "B‑Bomb"?**  
> Because it's so explosive and scary it makes your competitors stutter. 💣

### Innovation Quotient (IQ)
A 1–10 score measuring an artifact’s novelty, impact, elegance, scalability, and cultural fit. Target for B‑Bombs: **≥8/10**.

## 👥 Roles (Who Does What)

### Hustler
You – the human. Makes strategic decisions, handles offline tasks (calls, banking), validates quality, and keeps energy high.

### Orchestrator `[7‑7‑7]`
AI role. Responsible for strategic planning, tasklist generation, weekly reviews, and resource allocation. Uses skills in `Skills/`.

### Architect `[7‑7‑7]`
AI role. Generates session start/end prompts, reviews Builder outputs, and ensures quality. Also used for ad‑hoc reviews.

### Builder
AI or human. Runs macros, creates session files, captures artifacts, promotes B‑Bombs, logs insights.

### Sweeper `[7‑7‑7]`
Script‑based (not AI). Maintains folders, generates MOCs and Trackers, archives sessions, and enhances dashboards. The user runs Sweeper macros.

### Slasher `[7‑7‑7]` (Advanced)
AI role for compliance validation (regulatory, cultural, security). Not included in base 7‑7‑7; available as a power‑user add‑on.

## 📂 7‑7‑7 Specific Terms `[7‑7‑7]`

### Focus
A tracked area of work (e.g., `ai-engineering`, `freelance`, `digital-products`). Defined in `Focuses.md`. Used to tag sessions, artifacts, B‑Bombs, and insights.

### Focus Manager
A script macro (`Focus Manager.js`) that lets you add, edit, or delete focuses. Updates `Focuses.md` automatically.

### MOC (Map of Content)
A markdown file (one per focus) that uses Dataview queries to automatically list all sessions, artifacts, B‑Bombs, and insights tagged with that focus. Generated by `Sweeper – Create MOC.js`.

### Tracker
A markdown file (one per focus) that contains a weekly progress table (weeks 1–7) for the current cycle. Generated by `Sweeper – Create Tracker.js`. You fill in goals, progress, and blockers.

### Cycle X / Week Y
The organisation scheme: `Cycle 1` (first 7‑week block), `Week 1` (first week of that cycle). Used in folder paths (`Artifacts/Cycle 1/Week 1/`) and frontmatter tags (`#7/1/1`).

### Sweeper Scripts
JavaScript macros that automate housekeeping:
- `Sweeper – Create MOC.js` – generates MOCs for all focuses.
- `Sweeper – Create Tracker.js` – generates trackers for all focuses.
- `Sweeper – Archive Session.js` – moves a session to archive.
- `Sweeper – Archive All Active Sessions.js` – bulk archive.
- `Sweeper – Enhance MOCs & Trackers.js` – injects recent data into dashboards.

### Skills
Markdown files in `Skills/` that teach an AI (Claude, ChatGPT, etc.) how to act as an Orchestrator, Architect, or Builder. Example: `Orchestrator – AI‑Suplex Tasklist Generator.md`.

### Combined Tasklist
A markdown file that aggregates next actions from session ends, artifacts, and manual captures. Used for weekly planning. Generated by the `Orchestrator – Combined Tasklist Generator` skill.

### Weekly Review
A strategic summary of the past week’s sessions, insights, and next actions. Generated by the `Orchestrator – Weekly Review` skill after the user runs `Sweeper – Enhance MOCs & Trackers`.

### Session End Report
A structured report (using `Session-Report-Template.md`) created by the `Architect – Session End Report Generator` skill from a filled session end prompt.

## 🔄 Session Protocols (Same as Core)

### Session Start
A command that begins a focused work block. In the 7‑7‑7 Edition, the `Session Start` macro also prompts for **focus**, **cycle**, and **week**.

### Session End
A command that closes a session. The `Session End` macro captures rating, completion status, insights, and next actions.

### Split Session
A session that contains two distinct work blocks without formally ending the first. Useful for waiting periods.
